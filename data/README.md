# Dataset Directory (`data/`)

This directory holds the 25-class subset configuration, deterministic train/validation split indices, and the downloader for the [Food-101](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/) dataset.

## Files

| File | Tracked | Description |
|---|---|---|
| `subset_classes.json` | Yes | Canonical ordered list of the 25 supported Food-101 classes (`0..24`). |
| `download_food101.py` | Yes | Idempotent CLI and library module that downloads Food-101 via `torchvision` and writes `subset_manifest.json`. |
| `splits.json` | Yes (generated by Notebook 01) | Stratified 90% train / 10% validation indices for the 18,750 training images (`seed=42`). |
| `subset_manifest.json` | Generated | Maps each of the 25 classes to its Food-101 label index and train/test image counts (`750` / `250`). |
| `raw/` | Git-ignored | `torchvision.datasets.Food101` download & extraction root (~5 GB on disk). |

## Usage

```bash
# Download Food-101 (~5 GB) and verify the 25-class subset manifest:
python data/download_food101.py --yes
```
